# Chai v0.1.13

Chai now includes a local bridge so trusted agents on your computer can work
with Gmail and WhatsApp through your running desktop app.

## Changes

- Bearer-authenticated MCP Streamable HTTP and JSON RPC on loopback only,
  with status and recent activity visible in Settings.
- Contact/group resolution, conversation reading, per-recipient send results,
  stable send request IDs, and persistent response-watch tasks. External agents
  handle tasks; Chai does not send automatic replies.
- WhatsApp contact-name resolution and unread-count fixes.
- Re-pairing after an expired/logged-out session keeps the old credentials in
  a private backup and starts a fresh pairing session.
- Pairing QR codes rendered on-device instead of sent to an external image
  service.
- Baileys pinned to `7.0.0-rc12`, which contains the upstream fix for
  [CVE-2026-48063](https://github.com/WhiskeySockets/Baileys/security/advisories/GHSA-qvv5-jq5g-4cgg).
- Local Notes-group notification helper with exact group pinning and explicit
  handling of uncertain sends. It does not create an investment collector or
  recurring schedule.

## Install and update

Download the DMG matching your Mac (arm64 for Apple silicon, x64 for Intel), or
the Windows x64 installer. Builds are unsigned. On macOS, use right-click → Open
for the first launch; Windows may show a SmartScreen prompt. Install over the
previous version to preserve local data and account sessions. Do not clear app
data as part of a normal update.

This release follows the existing required-update policy: versions older than
0.1.13 are directed to this release for manual installation.

After launch, Settings → Local agent bridge should show Running. WhatsApp must
be paired with your phone and Gmail must be connected before those transports
can send. Phone pairing and reconnect were verified on the installed Mac, and one user-
authorized setup notification returned a valid provider message ID. Gmail OAuth
with your account, recipient-device/read confirmation, and full Windows UI
acceptance remain manual checks.

Bridge setup: [docs/AGENT_BRIDGE.md](https://github.com/no4jargon/Janus-Layer-0/blob/v0.1.13/docs/AGENT_BRIDGE.md).
